# Browser Vim Basics

Vimium C の操作を参考にした、Chrome 系ブラウザー向けの最小限の拡張機能です。

| キー | 操作 |
| --- | --- |
| `gt` | 次のタブへ移動（末尾から先頭へ戻る） |
| `gT` | 前のタブへ移動（先頭から末尾へ戻る） |
| `f` | 表示中のリンク・ボタン・入力欄などにヒントを表示 |

`f` の後は表示された文字を入力して対象を選びます。`Backspace` で一文字戻り、`Esc` で終了します。入力欄などで文字を編集中はショートカットを使いません。

## インストール

Chrome / Chromium の拡張機能画面を開き、デベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」から、この `browser-vim` ディレクトリを選びます。

ブラウザーの内部ページ、拡張機能ページなど、コンテンツスクリプトを実行できないページでは操作できません。ヒントは現在のフレーム内にある表示中の要素を対象にします。

反応しない場合は、通常の Web ページを再読み込みしてから、ツールバーの拡張機能アイコンを開いて状態を確認してください。「このページで有効です」と表示される場合はページ上の入力欄からフォーカスを外して試します。コードを更新したときは `chrome://extensions` で拡張機能の再読み込みも必要です。
